# Итоговый баннер CallCenter Command Center

## Назначение

Один экран для собственника, который показывает состояние всех точек, телефонов, звонков и операторов за 3 секунды.

## Главная идея

Не смотреть отчёты ради отчётов. Экран должен сразу отвечать на вопросы:

1. Где сейчас бизнес не принимает звонки?
2. Какие телефоны отключены или без heartbeat?
3. Сколько звонков не принято?
4. Кто не перезвонил клиенту?
5. Какие операторы создают риск потери клиентов?
6. Какие точки нарушают SLA?
7. Какие действия нужно выполнить прямо сейчас?

## Структура слайда

### Верхний баннер KPI

- точек под контролем;
- телефонов;
- звонков сегодня;
- непринятых звонков;
- просроченных перезвонов;
- критических сигналов.

### 10 графиков внутри одного кадра

1. Доступность точек.
2. Исход звонков.
3. Состояние телефонов.
4. Пропуски по точкам.
5. Причины плохих звонков.
6. Контроль обратного звонка.
7. Потери по часам.
8. Операторы: риск потери клиента.
9. SLA ответа по точкам.
10. Воронка: звонок → ответ → решение → следующий шаг → продажа.

## Красная логика

Красным подсвечивается только то, что требует действия:

- телефон отключён;
- оператор не отвечает;
- звонок не принят;
- перезвон просрочен;
- точка недоступна;
- оператор повторяет ошибку;
- продажа под риском потери.

## Нижняя строка действий

Экран должен показывать максимум три первоочередных действия:

1. какую точку спасать;
2. какому оператору назначить перезвон или разбор;
3. какие просроченные действия закрыть до конкретного времени.

## Источники данных для внедрения

- виртуальная АТС;
- события звонков: ringing, answered, busy, failed, no-answer;
- SIP registration и SIP OPTIONS heartbeat;
- мобильный heartbeat приложения оператора;
- CRM-статусы обращений;
- GPT-анализ звонков и чатов;
- журнал перезвонов и SLA.
