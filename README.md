# CallCenter — ЯКасса / Телемедиа

Самоулучшающаяся система контроля звонков, доступности телефонов, операторов и всех бизнес-точек.

## Главный принцип

**Звонок → обнаружение проблемы → автоматическое действие → повторная проверка → улучшение стандарта.**

## Первый управленческий экран

Итоговый экран должен за три секунды показывать:

- все точки и их доступность;
- непринятые и плохие звонки;
- отключённые телефоны и потерянный heartbeat;
- просроченные обратные звонки;
- операторов с высоким риском потери клиента;
- SLA по каждой точке;
- воронку от входящего звонка до продажи;
- три действия, которые нужно выполнить прямо сейчас.

Материалы итогового слайда хранятся в папке `design/command-center/`.
